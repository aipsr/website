# Project Instructions

This repository is the website of REDES-IA (https://redes-ia.org/), a network of academics researching the social, economic and political implications of AI. Its purpose is knowledge transfer from academia to stakeholders: policymakers, civil society, industry, media and the public.

- Static HTML/CSS site, deployed on Netlify from GitHub (github.com/aipsr/website). Preserve the static structure unless there is a strong reason to add tooling.
- Content may be in Spanish, Catalan and English; keep each page in its own language.
- Keep the tone clear and evidence-based, aimed at informed non-specialists.
- Ask before pushing to GitHub: pushing publishes the site.
- Avoid unrelated refactors or visual churn.
